# Frontend Assignment Documentation

## Overview

This project is a responsive web page developed using vanilla HTML, CSS, and JavaScript based on the provided Figma design specifications.

## Features Implemented

- Fully responsive layout for desktop, tablet, and mobile devices
- Sticky header with smooth show/hide transitions on scroll
- Interactive image carousel
- Hover zoom preview effect on carousel images
- Semantic HTML5 structure
- Modern CSS using Flexbox and Grid
- Smooth animations and transitions
- Cross-browser compatible implementation

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## Folder Structure

/project-root
│── index.html
│── styles.css
│── script.js
│── /assets

## How to Run

1. Download or clone the repository
2. Open index.html in any modern browser

## Notes

- No external frameworks or libraries were used
- Code is organized and commented for readability and maintenance
